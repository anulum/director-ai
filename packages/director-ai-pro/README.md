# director-ai-pro

The **pro** commercial tier for [Director-AI](https://github.com/anulum/director-ai),
the response-level LLM hallucination guardrail.

This package layers the LicenseRef-BUSL-1.1-ANULUM-TDM advanced modules on top of the
free Apache-2.0 `director-ai` core. Installing it pulls the core automatically:

```bash
pip install director-ai-pro
```
